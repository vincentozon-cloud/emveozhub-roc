# eMVeOzHub // Risk Operations Center (ROC)

Project Overview:
An AI-driven security monitoring dashboard designed to evaluate real-time telemetry and calculate neural-weighted risk scores. Built with a focus on "Fail-Safe by Design. Secure by Default."

Architecture:
- Neural Risk Scoring: Heuristic analysis of incoming signals for threat probability.
- Asynchronous Ingestion: High-performance capture layer for system telemetry.
- Hardened Baseline: Next.js 15 App Router with zero-trust configuration.

Technical Stack:
- Framework: Next.js 15 (React Compiler)
- Styling: Tailwind CSS v4 (CSS-first engine)
- Language: TypeScript (Type-safe logic)

Installation:
1. git clone [your-repo-link]
2. npm install
3. npm run dev
